# Detailed thread clocking remains unqualified

On 2026-10-29, an independent material-ray diagnostic suggested that much of the detailed McMaster 91290A111 screw / 94459A140 insert overlap came from arbitrary relative thread clocking. A +153° screw rotation about its already-seated world +X axis substantially reduced overlap in twelve sampled rays. Those samples still had nonzero overlap; the planned fourth radius was not completed. They were never a global mating result. The [earlier diagnostic](https://github.com/Valpatel/gyropup/issues/66#issuecomment-6494976984) records their limits and exact inputs.

This follow-up used released cad-agent v0.4.2, exact asserted private STEP hashes, the same seat and insert position, and the candidate rotation. It requested all three Boolean results, topology validation and aggregate-error-aware volume/conservation measurements through the committed `tools/volume_probe.py`. No tolerance or collision exclusion changed.

**Result: inconclusive.** Preparation reached `cut_a` and then hit its 900-second limit (exit 124). No complete fixed BREP bundle or volume/conservation receipt was produced. The `common` phase advancing does not supply its volume or a clearance result. The initial invocation had already failed before geometry import because it supplied flattened matrices instead of the required nested 3×4 form; its rejected-input log is preserved separately.

The [numeric status receipt](result.json), [corrected run log](clocked-run.log), [initial invocation log](rejected-flat-matrix.log) and [reproduction script](run-clocked-probe.sh) preserve this bounded attempt. The public script only makes the run-root path configurable; its original and public hashes are recorded. It needs the exact private STEP cache and isolated runtime. Every run needs a new output directory: the preparation tool intentionally refuses an existing bundle. The private CAD is not published here.

This is not evidence that the hardware cannot mate, nor is it a fit pass. Preserve the source-bound threaded diagnostic separately from public no-thread preview geometry and from PCB seating, screw-tip clearance, engagement, tool access and physical insert coupons. Do not transfer this clocking to a different screw length or to the missing 91290A113 manufacturer model. No carrier part, selected fastener, operating limit or readiness status changed. Any renewed whole-geometry attempt needs a justified method and bounded run, not an increased acceptance tolerance.
