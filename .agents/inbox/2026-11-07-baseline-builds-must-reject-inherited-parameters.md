# No parameters argument does not erase an inherited variant

On 2026-11-07, source review of the issue #8 baseline inspection plan found that `hip-frame-study.use_params(out,None)` creates output but leaves an inherited `GYROPUP_HIP_PARAMS` unchanged. `fivebar.py` reads that variable at import. Therefore an empty parameters argument does not establish a default-geometry baseline. This was caught before the proposed inspection; no contaminated native baseline was produced.

`python3 -B tests/evidence/test-study-media.py TopologyInspection` exercises the actual old helper in owned temporary output, verifies the inherited value remains, then exercises the actual new inspection worker with that variable planted. The worker rejects before output creation or any native import. The same nine kernel-free controls cover explicit synthetic 94-member source/STEP/receipt binding fixtures, missing-current with a legacy decoy, changed bytes, actual process-mask/pending-TERM cleanup, independent final capture/save failures, failed archive/nonquiescent handling, final-write failures with and without a primary exception, symlink-directory rejection, and an invalid output path rejected before handlers or final writes. The retained control log is [beside the proposed collector](../plans/hip-study/topology-controls.log). The actual current source/STEP binding is separately recorded in [the preparation proof](../plans/hip-study/topology-source-preflight.json). The unit fixtures do not make a frozen historical recipe an evergreen current-geometry requirement. No CAD kernel or FEA was run by these controls.

Rule: baseline workers reject inherited scenario variables before importing product CAD and record the effective parameters and their explicit origin. A caller passing None must not assume another layer cleared its environment. The import-only first inspection uses the exact retained STEP rather than loading the product builder; later source-based interfaces and parameter checks remain mandatory before candidate evaluation or FEA.

The current STEP receipt binds all 94 unchanged CAD sources, but its lug failures and physical limits remain. Imported topology cannot qualify fit, material strength, weighed mass or a later builder-specific edge selector. The original E1 safety-factor failure and all physical acceptance criteria remain unchanged. See the [bounded proposal](../plans/hip-study/geometry-interface-proposal.md).
