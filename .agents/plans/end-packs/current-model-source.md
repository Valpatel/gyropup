# Complete current presentation ownership, before artifact conversion

2026-11-10 source slice under the
[accepted architecture](https://github.com/Valpatel/gyropup/issues/193#issuecomment-6777578052).
`tools/site/robot_current_model.py` extends the existing collection/data contract;
it does not construct CAD, execute a recorded checkout or add another solver.
No public renderer route or asset has switched in this checkpoint.

The converter first requires the existing full current95-input guard, exact
accepted266 record/runtime and protected80 mesh identities, then reuses the
existing per-part byte/bounds validator for every224 original STL. The original
native producer inputs remain separate from current conversion code/runtime.
It emits82 stationary body,80 leg and62 same-collection turret records exactly
once. All output meshes are original bytes in world CAD-mm/Z-up. In a future
renderer each mesh is localized by its owner's inverse home world matrix; the
right module uses proper RZ180, never reflected geometry.

The source's pure `stance`, `ik`, `fk`, `motors` and `link_frames` functions are
read through a narrow AST boundary after exact source validation; importing the
CAD module and executing its top-level native imports is unnecessary. Current
made/bought turret frame declarations are read without constructing shapes.
The turret-box exporter supplies already-existing submechanism ownership rules;
it supplies no geometry. Joint datums are source-derived TM246/panX−40,
tilt140, pinionX−52.65, dialX−48, flywheelX25/Y±25.81 and flap(−87,0,91).
Sensors use the unchanged source shell faces and actual266 bounds, including
camera glassX±192.6/Z142.5 and the ears' actualY±155/Z160.

Grouped link/output screws are partitioned only inside disjoint motor-centred
source screw circles: AO-L PCD50/head8.5 and RS-04 output PCD36/head8.5. Every
triangle's three vertices must fit exactly one source circle, with0.001mm
float-export allowance. Both nonempty partitions must cover every original
triangle exactly once. Sorted original50-byte records must re-unite byte-exact;
no remeshing, hidden hardware or inferred fastening acceptance is allowed.
Each complete mesh and partition has four actual noncoplanar landmarks and
loader-order vertex indices for the later independent motion capture.

Complete inventory is separate from verified moving-component coverage. The
D69 hub includes a drum and axle in one source envelope; both turret motor
envelopes also combine housing and rotor features. Their support-owner placement
is a presentation choice, explicitly unresolved for internal motion. No rigid
mechanical ownership PASS is emitted. The separately named tyres/flywheels still
require wheel-spin capture; this limitation cannot excuse missing that coverage.
The64mm declaration describes the tyre band, not the whole wheel/motor width.
