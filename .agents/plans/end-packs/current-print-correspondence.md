## Two required contracts

`tools/evidence/manufacturing/retained_fit_history.py` owns the sole bounded
offline captured-data validator. Fixed reviewed receipt/job/snapshot anchors,
96 exact regular USTAR input files and current executed helper identities are
required. It calls the unchanged strict validator against actual original
artifacts. `verify-retained-fit-history.py` additionally runs the full unchanged
packager. Counts322/40/8 and all readiness flags remain false. Matching-input
snapshotf77 is distinct from recorded slice producer017e1e03. The original
[failed CI job](https://github.com/Valpatel/gyropup/actions/runs/42866125306/job/130005097895)
stays visible. No original receipt, output, source guard or default CLI changes.

`tools/site/assembly/robot_current_print_match.py` owns a thin current contract
around the unchanged sampler. It requires exact accepted266 collection/runtime/
frame identity, exact95 current input membership and bytes, all80 protected
leg mesh hashes and actual bytes, the original hip STL, sampler and historical
validator bytes, plus the complete historical receipt contract. Its explicit
measurement compares both actual hip meshes to the print original in the
existing fixed print transform, bidirectionally sampling vertices/triangle
centres at0.3011mm and rejecting the actual3mm wrong-frame control.

The native record's SHA is checked by its exact canonical original JSON
serialization in the consumer, allowing metadata and meshes to occupy separate
tracked source locations after a separately approved adoption. The measurement
CLI additionally requires the actual original `collection.json` bytes. The
mesh root is explicit; no legacy guide or private-history lookup supplies it.

The existing manufacturing mapper selects this contract explicitly for266.
There is no historical fallback after a current-source failure. Pending or
wrong proof remains pending. Existing project verification/readback can reuse
the original immutable geometry-only3MF only after the new current match is
accepted. Scope stays L/Rhip, generic bed, unsliced and physically unqualified.
Unrelated parts are not enabled. No generic CAD/UI implementation is forked.
