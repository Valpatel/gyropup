# Browser simulation snapshot

These browser meshes and physics replays were generated by this repository's
simulation tools on 2026-10-25–26 and captured for the first public site on
2026-10-28. They are a historical demo, not a validation of the latest CAD or
proof of physical hardware performance. Current design reports live alongside
their workstreams under `exports/leg`, `exports/body`, and `exports/turret`.

The static site and local simulator consume exactly these files. To publish a
new simulation, regenerate using `python -m sim.robot_v2` / `tools/simulate.py`
with the appropriate reviewed source revision, review the results, and commit
this snapshot with the corresponding design change. Never substitute `rl/`
training artifacts. Do not distribute licensed vendor source CAD.
